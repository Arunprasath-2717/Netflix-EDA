## 📌 Overview

An end-to-end **Exploratory Data Analysis (EDA)** project on the Netflix Movies & TV Shows dataset, built as part of the **Pluto Academy AI & ML Internship Program**. This project covers the full analytics workflow — from raw, messy data to cleaned data, actionable insights, and visual storytelling.

## 🗂️ Dataset

**Netflix Movies & TV Shows Dataset** — 8,800+ titles with details on type, director, cast, country, release year, rating, and genre.
📎 Source: [Kaggle — Netflix Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows)

## 🔧 What This Project Covers

| Stage | Description |
|---|---|
| 🧹 **Data Cleaning** | Handled missing values in `director`, `cast`, `country`; fixed inconsistent date formats |
| 🔍 **EDA** | Answered 5 key questions using Pandas (`value_counts`, `groupby`, etc.) |
| 📊 **Visualization** | 7 chart types — bar, line, pie, histogram, heatmap, and scatter plots |
| 💡 **Insights** | 5 data-backed business insights derived from the analysis |

## 📈 Key Findings

- 🎥 Movies outnumber TV shows by more than 2:1
- 🇺🇸 The United States dominates content production, followed by India
- 📆 Content additions exploded between 2015–2019, dipping slightly during COVID-19
- 🔞 TV-MA is the most common content rating — skewing toward mature audiences
- ⏱️ Most movies run between 90–100 minutes, in line with standard runtimes
